ADK Router JS Usage Guide

TypeScript ADK OpenRouter LiteLLM

Quick Start

Install and create a model with OpenRouter:

# Install
npm install adk-router-js

# TypeScript Usage
import { getModel, OpenRouterProvider, LiteLLMProvider } from 'adk-router-js';

// Method 1: Using getModel helper
const model = getModel({
    modelName: "xiaomi/mimo-v2-flash:free",
    provider: "openrouter",
    apiKey: process.env.OPENROUTER_API_KEY
});

// Use with ADK Agent
import { LlmAgent } from '@google/adk';

const agent = new LlmAgent({
    model: model,
    name: 'agent',
    instruction: 'You are a helpful assistant.',
});

// Method 2: Using OpenRouterProvider class
const provider = OpenRouterProvider.fromEnv();
const model2 = await provider.createModel("xiaomi/mimo-v2-flash:free");

// Method 3: Using LiteLLMProvider directly
const liteProvider = LiteLLMProvider.getInstance();
const model3 = liteProvider.createModel(
    "qwen/qwen3-preview:free",
    "openrouter",
    process.env.OPENROUTER_API_KEY
);

Supported Environment Variables

Set these environment variables for automatic configuration:

OpenRouter

OPENROUTER_API_KEY=your_openrouter_api_key
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1

Base URL is optional - defaults to https://openrouter.ai/api/v1

OpenAI

OPENAI_API_KEY=sk-...

Anthropic

ANTHROPIC_API_KEY=sk-ant-...

Azure OpenAI

AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/

Using LiteLLM Parameters

ADK Router supports all standard LiteLLM parameters:

Common Parameters

const modelOptions = getModel({
    modelName: "openrouter/qwen/qwen3-preview:free",
    provider: "openrouter",
    apiKey: "YOUR_KEY",
    temperature: 0.7,
    maxTokens: 4096,
    topP: 0.9,
    frequencyPenalty: 0.1,
    presencePenalty: 0.1,
    stop: ["\n\n"],
});

// With streaming
const streamingModel = getModel({
    modelName: "openai/gpt-4o",
    streaming: true,
    timeout: 120,
});

Creating Custom Providers

Add support for any OpenAI-compatible endpoint:

import { registerProvider, getModel } from 'adk-router-js';

registerProvider("my-custom", {
    base_url: "https://my-endpoint.com/v1",
    env_key: "MY_CUSTOM_API_KEY",
    name_prefix: "custom",
    description: "My Custom Provider",
    category: "custom",
});

// Use your custom provider
const model = getModel("my-model", "my-custom");

// With environment variables
// MY_CUSTOM_API_KEY=your_key_here

Available Methods

import { 
    getModel, 
    OpenRouterProvider, 
    LiteLLMProvider,
    registerProvider,
    getAllProviders,
    getProvidersByCategory,
    DEFAULT_PROVIDERS
} from 'adk-router-js';

// Get all available providers
console.log(getAllProviders());

// Get providers by category
const gateways = getProvidersByCategory('gateway');
const openAiBased = getProvidersByCategory('provider');

// Query provider info
const openrouter = DEFAULT_PROVIDERS.openrouter;
console.log(openrouter.base_url); // https://openrouter.ai/api/v1
