ADK Router Usage Guide

Python ADK OpenRouter LiteLLM

Quick Start

Install and create a model with OpenRouter:

pip install adk-router
from adk_router import get_model, OpenRouterProvider

# Simple approach
model = get_model(
    model_name="xiaomi/mimo-v2-flash:free",
    provider="openrouter",
    api_key="YOUR_API_KEY"
)

# Or use environment variables
provider = OpenRouterProvider.from_env()
model = provider.create_model("xiaomi/mimo-v2-flash:free")

Environment Variables

Set environment variables for automatic configuration:

OpenRouter

OPENROUTER_API_KEY=your_openrouter_api_key
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1

Base URL is optional - defaults to https://openrouter.ai/api/v1

OpenAI

OPENAI_API_KEY=sk-...

Anthropic

ANTHROPIC_API_KEY=sk-ant-...

Azure OpenAI

AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/

Using LiteLLM Parameters

ADK Router supports all standard LiteLLM parameters:

Common Parameters

from adk_router import get_model

model = get_model(
    model_name="openrouter/qwen/qwen3-preview:free",
    provider="openrouter",
    api_key="YOUR_KEY",
    temperature=0.7,
    max_tokens=4096,
    top_p=0.9,
    frequency_penalty=0.1,
    presence_penalty=0.1,
    stop=["\n\n"],
    response_format={"type": "json_object"},
)

Advanced Options

from adk_router import get_model

model = get_model(
    model_name="meta-llama/llama-3.70b-free",
    provider="openrouter",
    api_key="YOUR_KEY",
    temperature=0.3,
    max_tokens=8192,
    timeout=120,
    stream=True,
    rate_limit_multiplier=1.0,
    fallback_to_openai=False,
)

Creating Custom Providers

Add support for any OpenAI-compatible endpoint:

from adk_router import register_provider, get_model

register_provider("my-custom", {
    "base_url": "https://my-endpoint.com/v1",
    "env_key": "MY_CUSTOM_API_KEY",
    "name_prefix": "custom",
    "description": "My Custom Provider"
})

# Use your custom provider
model = get_model("my-model", provider="my-custom")

# With environment variables
# MY_CUSTOM_API_KEY=your_key_here

With ADK Agent

from google.adk.agents import LlmAgent
from adk_router import OpenRouterProvider

# Method 1: Using provider class
provider = OpenRouterProvider.from_env()
model = provider.create_model("xiaomi/mimo-v2-flash:free")

# Method 2: Using get_model
from adk_router import get_model
model = get_model(
    model_name="qwen/qwen3-preview:free",
    provider="openrouter",
    api_key="YOUR_KEY"
)

agent = LlmAgent(
    model=model,
    name="research_agent",
    description="Researches topics using powerful free models",
    instruction="You are a research assistant. Be thorough and cite sources.",
)

# Run with ADK
# adk run agent.py
# or
# adk web
